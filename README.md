# Infinity AI Lab

Automatización, inteligencia artificial, contenido digital, smart systems y soluciones tecnológicas modernas para negocios, eventos y marcas personales.

## Contenido

Este repositorio contiene la landing page de Infinity AI Lab (`index.html`): una página estática de un solo archivo, sin dependencias ni proceso de build. Todo el CSS y el JavaScript están en línea; la única carga externa es la fuente Poppins desde Google Fonts.

## Secciones

- **Automatización para Negocios** — WhatsApp inteligente, sistema de reservas, CRM inteligente
- **Contenido con Inteligencia Artificial** — videos IA, podcast y voz IA, diseño inteligente
- **IA para Redes Sociales** — crecimiento de marca, asistente virtual
- **Smart Home & Tecnología** — domótica, acceso con QR, sensores inteligentes
- **Tecnología para Eventos** — control de acceso, contenido en vivo
- **Educación y Capacitación IA** — cursos personalizados, asistentes educativos
- **Planes y Paquetes** — Básico, Profesional y Premium

## Uso local

Abre `index.html` directamente en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

Y visita http://localhost:8000

## Publicar con GitHub Pages

En **Settings → Pages**, selecciona *Source: Deploy from a branch*, rama `main` y carpeta `/ (root)`. La página quedará disponible en:

https://robersus.github.io/Infinity-AI-Lab/
