# Imágenes

Sube aquí tus imágenes (logo, fotos de servicios, banners, etc.).

## Cómo usarlas en `index.html`

Una vez subida una imagen a esta carpeta, referénciala desde `index.html` con una ruta relativa, por ejemplo:

```html
<img src="images/logo.png" alt="Infinity AI Lab">
```

## Recomendaciones

- Usa nombres de archivo simples y sin espacios (`logo.png`, `banner-hero.jpg`).
- Formatos recomendados: `.png` (logos/transparencias), `.jpg`/`.webp` (fotos).
- Comprime las imágenes antes de subirlas para que la página cargue rápido.
